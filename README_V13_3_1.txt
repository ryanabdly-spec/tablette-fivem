BLACK ACE V13.3.1 — SIGNALEMENTS

IMPORTANT : les fichiers de ce dossier doivent remplacer directement les fichiers de la tablette.
Le ZIP est volontairement plat : index.html, app.js, styles.css et les cartes sont à la racine.

La catégorie « ⚠ Signalements » est visible pour TOUS les comptes dans le menu latéral.
- chaque utilisateur voit uniquement ses propres signalements
- le Super Admin voit tous les signalements
- réponse + statut admin
- suppression par l'auteur ou le Super Admin

Le CSS et le JavaScript utilisent un numéro de version dans index.html pour éviter qu'un ancien fichier reste en cache.
